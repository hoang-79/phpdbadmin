Die Software phpdbadmin

phpdbadmin läuft auf Ihrem eigenen Server. Wir erhalten daraus keine Daten — es gibt keine Telemetrie und keinen Aufruf nach Hause. Der Web-Installer lädt bei der Einrichtung das neueste Release von GitHub herunter. Die SQL-Hilfe mit KI ist ausgeschaltet, bis Ihre Installation sie einschaltet; dann gehen Frage und Schema mit Ihrem eigenen Schlüssel an Anthropic, nie Daten aus Ihren Tabellen.
