{{ symbol:shield-check }} Ändern ohne Angst

Sie sehen, was passiert — bevor es passiert.

Ein Klick im Raster, ein Suchen-und-Ersetzen, ein Ergebnis im SQL-Editor: phpdbadmin zeigt jede Änderung als genaues SQL, führt sie gemeinsam aus und hebt die alten Werte auf.

  1. Erst die Vorschau

    Das SQL, das gleich läuft — mit den Zeilen, die ON DELETE CASCADE in anderen Tabellen mitlöscht.

    {{ symbol:file-code }} Vorschau wird genau so ausgeführt
    DELETE FROM customers
WHERE id = 7;

    {{ symbol:triangle-alert }} Löscht mit: 3 Zeilen in orders, 8 in order_items

  2. Dann alles oder nichts

    Alle Anweisungen laufen in einer Transaktion. Schlägt eine fehl, bleibt die Datenbank, wie sie war.

    {{ symbol:layers }} Transaktion
    • {{ symbol:check }} UPDATE orders … (3)
    • {{ symbol:check }} DELETE FROM customers … (1)
    • {{ symbol:circle-check }} COMMIT

  3. Und zurück, wenn nötig

    phpdbadmin sichert die Werte vorher. Ein Klick stellt sie wieder her — auch Tage später.

    {{ symbol:circle-check }} 4 Zeilen geändert{{ symbol:undo-2 }} Rückgängig

EXPLAIN

Langsame Abfragen sehen, nicht raten.

Der Ausführungsplan erscheint als Baum mit Kosten und Zeilen — und mit Hinweisen, wo ein Index fehlt. Auf Wunsch misst phpdbadmin mit ANALYZE.

  • {{ symbol:check }} Pläne von MariaDB, MySQL, PostgreSQL und SQLite im selben Format
  • {{ symbol:sparkles }} SQL-Hilfe mit KI, wenn Sie sie einschalten: eigener Schlüssel, gesendet werden nur Frage und Schema — nie Daten

{{ symbol:shield }} Sicherheit

Ein Werkzeug mit Zugang zu Ihren Daten muss streng sein.

phpdbadmin ist von Anfang an mit einem Bedrohungsmodell gebaut und nach OWASP geprüft — in zwei Durchgängen, ohne offenen hohen Befund.

  • {{ symbol:key-round }}

    Anmelden ohne Passwort

    Mit Passkey oder einem Code per Mail. Es gibt keine Kontopasswörter, die man erraten oder stehlen könnte.

  • {{ symbol:lock }}

    Zugangsdaten verschlüsselt

    Passwörter der Verbindungen liegen verschlüsselt in der App-Datenbank — oder gar nicht, wenn Sie sie nur für die Sitzung angeben.

  • {{ symbol:network }}

    Nur erlaubte Server

    Sie legen fest, zu welchen Servern phpdbadmin verbinden darf. Das schützt Ihr internes Netz vor Umwegen.

  • {{ symbol:users }}

    Rechte je Verbindung

    Lesen, schreiben, verwalten — je Konto und Verbindung. phpdbadmin warnt, wenn ein Datenbankkonto alle Rechte auf dem Server hat.

  • {{ symbol:shield-check }}

    Gehärtet

    Content-Security-Policy mit Nonce, Schutz vor CSRF, gedrosselte Code-Prüfung, keine Telemetrie. Nichts meldet nach Hause.

  • {{ symbol:signature }}

    Signierte Releases

    Der Installer prüft Grösse, SHA-256 und die Ed25519-Signatur jedes Releases, bevor er etwas entpackt.

{{ symbol:zap }} Installation

In wenigen Minuten auf Ihrem Server.

Auf Webhosting ohne Konsole mit dem Web-Installer, auf dem eigenen Server mit drei Befehlen. Beides ohne Konto bei uns — es gibt keines.

{{ symbol:globe }} Mit dem Web-Installer

Für Webhosting ohne Konsole — eine einzige PHP-Datei.

  1. Eine eigene (Sub-)Domain anlegen, z. B. db.ihre-domain.ch, und HTTPS einschalten.
  2. phpdbadmin-installer.php in deren leeren Ordner hochladen.
  3. Die Datei im Browser öffnen und den Schritten folgen.

Der Installer prüft den Server und erklärt jeden Befund in Klartext, erkennt rund 20 Hoster, löst nach Rückfrage, was er selbst lösen kann, prüft die Signatur des Releases, legt das Programm wenn möglich ausserhalb des Webordners ab, richtet App-Datenbank, Mail und Ihr Konto ein — und löscht sich am Ende selbst.

{{ symbol:download }} Installer herunterladen

{{ symbol:terminal }} Mit der Konsole

Für den eigenen Server, eine VM oder Laravel Herd.

$ git clone {{ repository }}.git
$ cd phpdbadmin
$ composer setup

composer setup installiert die Abhängigkeiten, baut die Oberfläche, richtet die App-Datenbank ein, prüft das System und fragt nach Ihrem Namen und Ihrer Mail-Adresse. Am Ende steht ein Einrichtungslink, der Sie anmeldet und Ihren Passkey anlegt.

Aktualisieren: git pull und composer upgrade.

Voraussetzungen

PHP
8.5 mit pdo, mbstring, openssl — dazu der Treiber je Datenbank (pdo_mysql, pdo_pgsql, pdo_sqlite)
Webserver

App-Datenbank

HTTPS

Optional

{{ symbol:circle-alert }} Fragen

Häufige Fragen

Was kostet phpdbadmin? {{ symbol:chevron-down }}

Nichts. phpdbadmin ist Open Source unter der MIT-Lizenz, auch für den Einsatz in Firmen. Sie betreiben es auf Ihrem eigenen Server oder Webhosting.

Hat phpdbadmin etwas mit phpMyAdmin zu tun? {{ symbol:chevron-down }}

Nein. phpdbadmin ist ein eigenständiges Projekt mit eigenem Code und gehört weder zu phpMyAdmin noch zu phpPgAdmin. Anders als diese arbeitet es mit vier Datenbanken in einer Oberfläche.

Verlassen meine Daten den Server? {{ symbol:chevron-down }}

Nein. phpdbadmin läuft bei Ihnen und meldet nichts nach Hause — keine Telemetrie, keine Statistik.

Die einzige Ausnahme ist die SQL-Hilfe mit KI: Sie ist ausgeschaltet, bis Ihre Installation sie einschaltet, und braucht dann je Konto einen eigenen Schlüssel. Gesendet werden nur Ihre Frage und das Schema (Tabellen, Spalten, Typen, Schlüssel) — nie Daten.

Welche Datenbanken und Versionen werden unterstützt? {{ symbol:chevron-down }}

MariaDB ab 10.6, MySQL ab 8.0, PostgreSQL ab 14 und SQLite. Die Tests laufen gegen die aktuellen Versionen und gegen diese Untergrenzen.

Brauche ich HTTPS? {{ symbol:chevron-down }}

Für Passkeys ja — Browser erlauben sie nur über HTTPS (ausser auf localhost). Für ein Werkzeug mit Zugang zu Ihren Datenbanken ist HTTPS ohnehin Pflicht; die meisten Hoster schalten ein kostenloses Zertifikat mit einem Klick ein.

Können mehrere Personen damit arbeiten? {{ symbol:chevron-down }}

Ja. Sie laden Kolleginnen und Kollegen per Mail ein und vergeben Rechte je Verbindung: lesen, schreiben oder verwalten. Jede schreibende Aktion steht im Protokoll, und die aktiven Sitzungen lassen sich jederzeit beenden.

Warum braucht der Installer eine eigene (Sub-)Domain? {{ symbol:chevron-down }}

Damit das Programm ausserhalb des Webordners liegen kann und nur der öffentliche Teil erreichbar ist. In einem Unterordner einer bestehenden Website wäre das nicht sicher möglich — deshalb richtet der Installer phpdbadmin nur auf einer eigenen (Sub-)Domain ein.

Wie aktualisiere ich? {{ symbol:chevron-down }}

Mit Konsole: git pull und danach composer upgrade — das holt die Abhängigkeiten, baut die Oberfläche, führt die Migrationen aus und prüft das System. Neue Versionen stehen unter Releases.

Gibt es phpdbadmin auch gehostet? {{ symbol:chevron-down }}

Nein, bewusst nicht. Ein Werkzeug, das Ihre Datenbanken öffnet, gehört auf Ihren Server — neben die Datenbanken, nicht zu einem Anbieter dazwischen.

Bereit für Datenbanken ohne Herzklopfen?

Laden Sie den Installer herunter, oder sehen Sie sich zuerst den Code an. Beides kostet nichts.
